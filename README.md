# Решение прямой и обратной задач нелинейного уравнения Шрёдингера

Исследовательский проект по построению и сравнению нейросетевых моделей для нелинейного уравнения Шрёдингера (НУШ). В прямой задаче по параметрам яркого солитона вычисляется приближённое комплексное поле `u(x, t)`. В обратной задаче требуется восстановить параметры солитона по наблюдаемому полю.

Рассматривается уравнение

$$
i\frac{\partial u}{\partial t}+\frac{\partial^2 u}{\partial x^2}+\nu|u|^2u=0.
$$

Для построения обучающих примеров и проверки результатов используется точное решение яркого солитона из `solver.py` с параметрами `A` (амплитуда), `v` (скорость), `nu` (коэффициент нелинейности) и `x0` (начальный центр).

## Реализованные подходы

- **Модель на данных (data-driven)** — получает четыре параметра солитона и предсказывает действительную и мнимую части поля на всей сетке. Архитектура состоит из полносвязного энкодера и свёрточного декодера.
- **PINN** — принимает координаты `(x, t)` и четыре параметра; при обучении использует невязку дифференциального уравнения, начальное и граничные условия.
- **Гибридная модель** — предсказывает поле на сетке, обучается по точным решениям и дополнительно учитывает физическую невязку и сохранение нормы.

- **Модель обратной задачи** — CNN-энкодер с четырьмя свёрточными блоками принимает два канала наблюдаемого поля, `Re(u)` и `Im(u)`, на сетке 64 × 128 и восстанавливает четыре параметра `[A, v, nu, x0]`. При обучении используется ошибка восстановления параметров и дополнительная ошибка согласования восстановленного аналитического поля с наблюдением.
- **Метод Нелдера — Мида** — подбирает те же четыре параметра, минимизируя расхождение между аналитическим полем солитона и наблюдаемым полем без вычисления производных целевой функции. Реализация и сравнение с нейросетью находятся в `invers_evaluate.py`.

## Установка

Рекомендуется Python 3.10 или новее. Для выполнения предоставленных скриптов необходимы `numpy`, `torch`, `matplotlib`, `tqdm` и `scipy` (последняя библиотека нужна для реализации метода Нелдера — Мида).

В терминале, открытом **в корневой папке проекта**, выполните:

```bash
python -m venv .venv
```

Активируйте виртуальное окружение:

- **macOS / Linux:** `source .venv/bin/activate`
- **Windows PowerShell:** `.venv\Scripts\Activate.ps1`

Установите зависимости:

```bash
python -m pip install --upgrade pip
python -m pip install numpy torch matplotlib tqdm scipy
```

На некоторых системах команда Python называется `python3` или `py`. Для работы на GPU необходимо установить совместимую версию PyTorch согласно инструкции для своей платформы. Скрипты рассчитаны, в частности, на Apple Silicon (MPS); фактическое используемое устройство зависит от программы и доступности ускорителя.

## Порядок запуска прямой задачи

Перед генерацией данных создайте каталог `data` — `dataset.py` записывает файлы в него и самостоятельно не создаёт папку:

```bash
python -c "from pathlib import Path; Path('data').mkdir(exist_ok=True)"
```

### 1. Аналитическое решение

```bash
python solver.py
```

Скрипт строит пример точного солитона и сохраняет `data/test_solver.png`.

### 2. Модель на данных

```bash
python dataset.py
python train.py
python evaluate.py
```

Генератор создаёт 3000 примеров (значение по умолчанию) и сохраняет `params.npy`, `u_real.npy`, `u_imag.npy`, `x_grid.npy`, `t_grid.npy` в папке `data`. Обучение сохраняет `model.pth`, `norm_params.npy` и график `training_curves.png`. Для работы `evaluate.py` эти файлы уже должны существовать.

### 3. PINN

```bash
python pinn_train.py
python pinn_evaluate.py
```

Скрипт обучения сохраняет веса `data/pinn_model.pth` и графики процесса обучения. Оценка загружает обученные веса; запускать её до завершения обучения нельзя.

### 4. Гибридная модель

```bash
python hybrid_dataset.py
python hybrid_train.py
```

`hybrid_dataset.py` генерирует **3000 примеров**, а обучение выполняется в два этапа: предварительное обучение по данным и подключение физических слагаемых. Обучение сохраняет веса (`data/hybrid_model.pth`), параметры нормализации и графики функции потерь. Массивы полей требуют свободного места на диске и оперативной памяти при обучении.

В составе проекта пока не указан отдельный скрипт тестирования гибридной модели. Для самостоятельного сравнения её результатов с другими моделями потребуется программа оценки, использующая сохранённые веса и параметры нормализации.

## Порядок запуска обратной задачи

Обратная задача восстанавливает амплитуду `A`, скорость `v`, коэффициент нелинейности `nu` и начальный центр `x0` по наблюдаемому комплексному полю. Для сети используются два входных канала: действительная и мнимая части поля на сетке 64 × 128.

### 1. Архитектура обратной модели

Файл `invers_model.py` содержит класс `InverseNLSE`. Четыре свёрточных блока последовательно уменьшают пространственное разрешение, после чего полносвязные слои выдают четыре параметра. Для простой проверки формы выходных тензоров можно выполнить:

```bash
python invers_model.py
```

Эта команда **не обучает** модель: она только создаёт сеть и проверяет её выходы на случайных тензорах.

### 2. Обучение обратной модели

```bash
python invers_train.py
```

Скрипт генерирует в памяти 20 000 примеров по аналитической формуле солитона. К действительной и мнимой частям поля добавляется случайный шум с уровнем от 0 до 5% амплитуды. Используются диапазоны параметров из таблицы ниже, сетка `x ∈ [-20, 20]`, `t ∈ [0, 3]` и разбиение обучающей/проверочной выборки 90/10.

Оптимизатор — Adam (`lr=1e-3`), размер пакета — 64, максимум — 150 эпох, ранняя остановка после 20 эпох без улучшения. Функция потерь включает ошибку предсказания параметров с весом 1,0 и физическую согласованность с весом 0,5: восстановленное по предсказанным параметрам поле сравнивается с зашумлённым наблюдением.

Результаты обучения записываются в каталог `data/`:

- `inverse_model.pth` — веса лучшей модели;
- `inverse_norm_params.npy` — параметры нормализации;
- `inverse_training_curves.png` — графики обучения.

До запуска этой команды необходимо создать каталог `data/`, как показано в разделе «Порядок запуска прямой задачи». Генерация 20 000 массивов полей требует значительного объёма оперативной памяти.

### 3. Оценка и сравнение с методом Нелдера — Мида

После обучения запустите:

```bash
python invers_evaluate.py
```

Скрипт загружает `data/inverse_model.pth` и выполняет две проверки:

1. **Один тестовый случай** — параметры `(A=1.5, v=1.0, nu=1.0, x0=0.0)`, уровень шума 3%. Сравниваются восстановленные параметры, ошибка и время работы модели и метода Нелдера — Мида.
2. **50 случайных тестовых случаев** — обеим методикам передаются одинаковые зашумлённые поля. Оптимизация Нелдера — Мида выполняется отдельно для каждого примера с несколькими начальными приближениями, а нейросеть обрабатывает поля одним пакетом.

Для оптимизации используется `scipy.optimize.minimize(method="Nelder-Mead")`. Время чистого инференса нейросети измеряется после прогрева отдельно от подготовки входных данных. Время обработки одного примера и пакета из 50 примеров не следует смешивать при сравнении производительности.

Создаваемые графики:

- `data/inverse_comparison_single.png` — истинное, зашумлённое и восстановленные поля;
- `data/inverse_results_table.png` — результаты для одного тестового случая;
- `data/inverse_average_errors_by_ranges.png` — сравнение ошибок на 50 примерах;
- `data/inverse_scatter.png` — соответствие истинных и восстановленных параметров.

Конкретные значения ошибок и времени не зафиксированы в README: их нужно получать при выполнении скрипта с соответствующими обученными весами и указывать в отчёте только после фактического измерения.

## Параметры и воспроизводимость

Для генерации решений во всех рассмотренных скриптах используются следующие диапазоны параметров солитона:

| Параметр | Диапазон |
| --- | --- |
| `A` | 0.5…2.0 |
| `v` | −1.5…1.5 |
| `nu` | 0.3…2.0 |
| `x0` | −2.0…2.0 |
| `x` | −20…20 |
| `t` | 0…3 |
| Размер сетки | 64 точки по времени × 128 по координате |

Для прямой задачи модель на данных и гибридная модель используют отдельно сгенерированные обучающие выборки по 3000 примеров. PINN обучается по значениям физической невязки, начального и граничных условий в случайно выбранных точках. Для обратной задачи создаётся отдельная выборка из 20 000 зашумлённых полей. Размеры выборок и функции потерь различаются в соответствии с выбранными способами обучения.

Значения ошибок и времени выполнения зависят от обученных весов, тестовых данных и вычислительного устройства. Для воспроизведения результатов НИР следует использовать сохранённые веса и тот же набор настроек, с которым проводились описанные эксперименты. При повторном обучении численные результаты могут отличаться.

## Результаты и данные

Каталог `data/` создаётся в процессе работы и содержит массивы, веса моделей и изображения. Перед оценкой должны быть доступны соответствующие `.pth` и `.npy` файлы; если готовые веса не загружены в репозиторий, нужно сначала выполнить обучение. Время обучения зависит от устройства, размера выборки и текущих настроек скриптов.

Не следует добавлять в публичный репозиторий виртуальное окружение `.venv/`, временные каталоги `__pycache__/`, пароли, токены и другие секретные данные. Большие обучающие массивы и веса можно хранить отдельно, указав способ их получения.
